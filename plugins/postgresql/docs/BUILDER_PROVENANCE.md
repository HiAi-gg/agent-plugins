as-is. `packages/postgres-mcp`, `tests/`, and `docs/` are additive content
(application code + docs), not structural edits to the generated plugin.

## Builder issues discovered

1. `create --config` ignores `--force` on a non-empty output directory
   (throws "Output directory is not empty"); the directory must be removed
   first.
2. Generated README is a minimal scaffold, not a public-ready README.
3. Builder generates no LICENSE and no CHANGELOG (created manually).
4. `body-file` paths resolve relative to the config file directory, so the
   skill sources must live inside the repository (`skills-src/`) for
   reproducible builds.
